# Frequently Asked Questions

---

## General

### What is Infiniti?

Infiniti is an open-source chess engine written in modern C++20. It communicates using the Universal Chess Interface (UCI) protocol and can be used with any UCI-compatible chess GUI or from the command line.

### Is Infiniti free to use?

Yes. Infiniti is released under the [MIT License](../LICENSE). You are free to use, modify, and distribute it, including for commercial purposes, as long as you retain the copyright notice.

### Which platforms does Infiniti run on?

Infiniti builds and runs on **Linux**, **macOS**, and **Windows** (MSVC, MinGW/MSYS2, or Clang). See [Building](building.md) for full details.

### What strength does Infiniti play at?

Infiniti implements a solid set of modern chess programming techniques (PVS, NMP, LMR, transposition table, tapered HCE, NNUE). Its exact Elo depends on hardware and time control. With NNUE enabled on a modern CPU it plays well above club level, though it is not designed to compete with top-tier engines such as Stockfish.

## Building

### What compiler do I need?

You need a C++20-capable compiler:

| Compiler | Minimum version |
|----------|----------------|
| GCC | 10 |
| Clang | 12 |
| MSVC | 19.29 (VS 2019 16.10) |

### What is the minimum CMake version?

CMake 3.16 or later.

### The build fails with "C++20 not supported" — what do I do?

Upgrade your compiler to one of the versions listed above. On Ubuntu/Debian you can install a recent GCC with:

```bash
sudo apt install gcc-12 g++-12
CC=gcc-12 CXX=g++-12 cmake -B build -DCMAKE_BUILD_TYPE=Release
```

### Can I build just the engine without the web platform?

Yes. The C++ engine and the Node.js web platform are completely independent. Building with CMake produces only the engine binary.

### How do I run the tests?

```bash
cmake --build build
cd build
ctest --output-on-failure
```

## Usage

### How do I use Infiniti with a chess GUI?

Compile the engine, then add it to your GUI as a new UCI engine pointing at the `infiniti` (or `infiniti.exe`) binary. No additional configuration is needed — the engine advertises its options automatically via the UCI `uci` command.

Popular compatible GUIs: Arena, Cute Chess, BanksiaGUI, Lucas Chess, Scid vs. PC.

### What UCI options does Infiniti expose?

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `Hash` | spin | 16 | Transposition table size in megabytes (1–2048) |
| `UseNNUE` | check | true | Enable the NNUE neural network evaluator |
| `EvalFile` | string | *(empty)* | Path to a `.nnue` network file |

### How much hash memory should I allocate?

A good rule of thumb is **64–256 MB** for analysis and **16–128 MB** for engine-vs-engine games. Larger hash tables reduce collisions during long searches but consume more RAM. Hash size can be set in your GUI or via:

```
setoption name Hash value 128
```

### Can I use Infiniti for engine-vs-engine tournaments?

Yes. It supports all time-control modes (`wtime`/`btime`/`winc`/`binc`, `movetime`, `depth`, `infinite`) and responds correctly to `ucinewgame` between games.

## NNUE

### What is NNUE?

NNUE (Efficiently Updatable Neural Network) is a neural network architecture designed for fast incremental evaluation during tree search. It was popularised by Stockfish and is now standard in competitive engines. See [NNUE](nnue.md) for a full explanation.

### Where can I get a compatible NNUE network file?

Infiniti uses a HalfKP architecture with specific layer sizes (see [NNUE](nnue.md)). A compatible `.nnue` file must match the `NetworkWeights` struct in `nnue/network.h`. You can train one with tools such as [nnue-pytorch](https://github.com/official-stockfish/nnue-pytorch) using self-play data generated by Infiniti.

### How do I load an NNUE network?

Send these UCI commands before starting a search:

```
setoption name EvalFile value /absolute/path/to/network.nnue
setoption name UseNNUE value true
```

The engine prints `info string NNUE file loaded successfully` on success.

### What happens if no NNUE file is loaded?

Infiniti automatically falls back to the tapered hand-crafted evaluator (HCE). You can also explicitly disable NNUE:

```
setoption name UseNNUE value false
```

### The engine prints "NNUE load failed: cannot open file" — why?

Check that:
1. The path is correct and the file exists.
2. The path is absolute, or relative to the directory from which the engine binary was launched.
3. The file is a valid `.nnue` file matching Infiniti's expected format.

## Web Platform

### What is the web platform?

The `web/` directory contains a separate Node.js application that provides user authentication (email verification, password reset, TOTP 2FA), KYC document upload, transaction management, and a favourite games UI. It is unrelated to the chess engine itself.

### How do I run the web platform?

```bash
cd web
npm install
npm run start
```

Then open `http://localhost:3000`. See [web/README.md](../web/README.md) for the full list of environment variables.

### Does the web platform require any external services?

Most features work without external services. S3-compatible object storage is optional for KYC document uploads — without it, a non-persistent blackhole storage URI is used. An email service is optional too; in non-production mode, sent emails are exposed at `GET /api/dev/sent-emails` for local testing.

## Contributing

### How do I report a bug?

Open a [GitHub issue](https://github.com/GizzZmo/Infiniti/issues) with a minimal reproducible example (FEN + UCI sequence), the expected vs. actual behaviour, and your compiler/OS/CMake versions.

### How do I submit a feature or fix?

See [Contributing](contributing.md) for the full workflow. In short: fork, branch, implement, test, and open a pull request against `main`.

### Is there a code style guide?

Match the style of the surrounding file. Prefer `constexpr` and `inline` over macros. No external dependencies beyond the C++ standard library and POSIX threads. Run `clang-tidy` before submitting.
